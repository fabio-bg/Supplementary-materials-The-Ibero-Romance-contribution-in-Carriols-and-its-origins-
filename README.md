# Supplementary materials of the paper "The Ibero-Romance contribution in Carriols and its origins"
These are the supplementary materials of the paper "The Ibero-Romance contribution in Carriols and its origins". They contain the NEXUS file used to generate a NeighborNet comprising Carriols and 11 other languages, as well as a .csv table with attested variants for each Ibero-Romance-derived word in Carriols that we have identified.
